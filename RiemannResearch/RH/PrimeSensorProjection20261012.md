## Exact finite observation energy

For a finite set \(P\) of primes greater than 3, let
\(k_q\) be the actual Pareto Riesz representer of
\(\ell_q(f)=f(q)-f(q-1)-f(1)\). The existing exact Gram is

\[
\langle k_q,k_r\rangle=2+2q^2\mathbf1_{q=r}.
\]

For prescribed normalized observations \(c_q\), put

\[
E=\sum_{q\in P}c_q^2,\qquad
t=\sum_{q\in P}\frac{c_q}{q},\qquad
S=\sum_{q\in P}\frac1{q^2},\qquad
\mathcal J_P(c)=\frac12\left(E-\frac{t^2}{1+S}\right).
\]

The explicit minimum-norm interpolant is

\[
u_P(c)=\frac12\left(
\sum_{q\in P}\frac{c_q}{q}k_q-
\frac{t}{1+S}\sum_{q\in P}\frac{k_q}{q^2}\right).
\]

The new Lean module `PrimeSensorProjection.lean` proves

\[
\frac{\ell_q(u_P(c))}{q}=c_q\quad(q\in P),\qquad
\|u_P(c)\|^2=\mathcal J_P(c),
\]

and, for every actual Hilbert vector \(f\) with those observations, the
complete identity

\[
\boxed{\|f\|^2=\mathcal J_P(c)+\|f-u_P(c)\|^2.}
\]

Thus the observation lower bound is optimal for the specified observations.
The vector \(u_P(c)\) is a projection onto physical sensor directions. It is
not asserted to belong to the legal two-seed approximation space.

The improvement over the previous Cauchy-Schwarz estimate is exactly

\[
\boxed{
\mathcal J_P(c)=\frac{E}{2(1+S)}+
\frac{1}{4(1+S)}\sum_{q,r\in P}
\left(\frac{c_q}{r}-\frac{c_r}{q}\right)^2.
}
\]

All pair terms are retained, including both orders. The module also proves
\(E/[2(1+S)]\le\mathcal J_P(c)\le E/2\), nonnegativity, and the harmonic
specialization
\(\mathcal J_P((a/q)_q)=a^2 S/[2(1+S)]\). For that harmonic pattern the
improvement is zero; sharpening the observation inequality does not by
itself produce extra arithmetic gain.

Reproduction code for the 80-digit check:

```wl
ClearAll[weight, atom, entry, stage];
weight[period_, residue_] := weight[period, residue] =
  N[(PolyGamma[0, (residue + 1)/period] -
     PolyGamma[0, residue/period])/period, 80];
atom[{seed_, dilation_}, n_] :=
  dilation Mod[Quotient[n, dilation], seed];
entry[left_, right_] := Module[{period},
  period = LCM[Times @@ left, Times @@ right];
  Sum[atom[left, n] atom[right, n] weight[period, n], {n, 1, period}]];
stage[cutoff_] := stage[cutoff] = Module[{indices, gram, target, coeff},
  indices = Flatten[Table[{{2, d}, {3, d}}, {d, 1, cutoff}], 1];
  gram = Table[entry[indices[[i]], indices[[j]]],
    {i, 2 cutoff}, {j, 2 cutoff}];
  target = N[Log[indices[[All, 1]]], 80];
  coeff = PseudoInverse[gram, Tolerance -> 10^-60].target;
  <|"cutoff" -> cutoff,
    "rank" -> MatrixRank[gram, Tolerance -> 10^-60],
    "distance" -> 1 - target.coeff, "coeff" -> coeff,
    "indices" -> indices, "normalError" -> Max[Abs[gram.coeff - target]]|>];
old = stage[4]; new = stage[8]; primes = {5, 7};
observations = Table[
  Total[Extract[new["coeff"], Position[new["indices"], {_, prime}]]],
  {prime, primes}];
mass = Total[1/primes^2]; charge = Total[observations/primes];
energy = Total[observations^2];
sharp = (energy - charge^2/(1 + mass))/2;
coarse = energy/(2 (1 + mass));
defect = Sum[(observations[[i]]/primes[[j]] -
  observations[[j]]/primes[[i]])^2, {i, 2}, {j, 2}];
{N[{old["distance"], new["distance"],
    (old["distance"] - new["distance"])/old["distance"],
    sharp/old["distance"], coarse/old["distance"]}, 25],
 N[observations, 25], {old["rank"], new["rank"]},
 N[sharp - coarse - defect/(4 (1 + mass)), 3],
 N[Max[old["normalError"], new["normalError"]], 3]}
```
