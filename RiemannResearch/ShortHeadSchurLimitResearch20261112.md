# Fixed-pair limits for the signed short-head Schur term

Prepared 12 November 2026. Base inspected: `5b35111b06943923e861af1bc6b26b815e393e21`.

The highest-priority arithmetic bound is **still Open**. This update proves an exact
limit for the actual signed term and weakens the quantifiers in the sufficient
condition for RH. It does not provide the common bound.

## Exact object and hypotheses

Use the actual matched full-conductor divisor projections, not a squarefree
substitute. Let the positive periods `R j` be nested by divisibility and cofinal
for every conductor greater than one. Let `H j` tend to infinity, with no rate or
monotonicity assumption on H. Let A(H) be the existing canonical physical cutoff.

Write S_j for the full Q divisor space, U_j,H for the space generated by its
conductors greater than H, r_j for the actual P residual, and d_j for the
difference of the Q and P fits. Both norms and all projections use their complete
infinite tails. Define

```text
S_j(n,m) = Head_{A(H_j)}(r_j,
             Pi^Q_{S_j}(e_n-e_m) - Pi^Q_{U_j,H_j}(e_n-e_m)).
```

Lean names this real-valued quantity `shortSchur R j (H j) n m`.
The letter S in this displayed scalar is only notation; it is not an unsigned
Gram surrogate.

The exact finite identity is

```text
S_j(n,m) = zeta(2) [d_j(n)-d_j(m)]
           - Head_{A(H_j)}(r_j, K_high;j(n,m))
           - Tail_{A(H_j)}(r_j, K_j(n,m)).
```

Both subtracted terms retain their signs. For fixed n and m the sharper estimate is

```text
|Head_A(r_j,K_high;j(n,m))|
    <= |n-m| zeta(2) ||r_j||_P / H_j
    <= |n-m| zeta(2) / H_j.
```

The finite estimate requires H_j>0, A<=H_j, and n,m<=H_j. These hold eventually.
The existing complete-tail localization gives a vanishing signed tail. Therefore,
for every fixed pair of sites, including site zero,

```text
S_j(n,m) -> zeta(2) [d(n)-d(m)].
```

This limit theorem has no RH assumption and does not assume the limiting residual
vanishes. It is pointwise in the pair, not uniform in a growing window.

## Weaker sufficient condition

It suffices to find ONE real constant C and ONE positive integer modulus L such
that, for every fixed positive n,m congruent modulo L,

```text
for every stage threshold J, some j>=J satisfies |S_j(n,m)| <= C.
```

The good stages may depend on the pair; no common subsequence is required.
No simultaneous estimate over all n,m<=H_j is required. C must be independent
of n, m and j. The existing eventual growing-window bound implies this condition.

Passing to the exact limit gives

```text
|d(n)-d(m)| <= C / zeta(2)
```

for every such pair, with no additive high-part or tail allowance. The existing
full-conductor residue-oscillation theorem then implies Mathlib's
`RiemannHypothesis`.

The existence of such a common C is equivalent, under the stated exhaustion
hypotheses, to `QFullDisplacement.qResidual = 0`. In the zero-residual direction,
C=1 suffices because every fixed-pair signed term tends to zero.
This equivalence identifies the arithmetic gap; it does not discharge it.

There is also a precise obstruction: if RH fails, then for every fixed L>0 and
every C there is a single positive congruent pair n,m whose signed short-head
term eventually has absolute value greater than C. The witnesses may depend
on C. This does not assert that one fixed pair diverges to infinity.

## Attempt and remaining work

The high-conductor estimate can be sharpened because the physical pair stays
fixed while H grows. The tail already has an unconditional provider. Neither
step controls the limiting displacement uniformly across all pairs.

Strong Hilbert convergence supplies bounds with site-dependent evaluation
factors. It does not supply one C for all physical pairs. Finite numerical
samples and diagonal-only Gram comparisons do not supply that missing bound
either. The next proof obligation is now the weaker pairwise cofinal common-C
estimate above; the original uniform-window estimate remains a sufficient
stronger target.
